# Agent notes

The glossary for this repository is [CONTEXT.md](CONTEXT.md).

Read CONTEXT.md before exploring this repository and before naming a domain concept. Use its term for that concept. Do not substitute a word listed under `_Avoid_`. When the concept is missing from CONTEXT.md, say so. Do not invent a synonym.

The language covers pool identity, pool shape, snapshots, price curves, chain history, peers, and the services that own them.
